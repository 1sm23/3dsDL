**扫码安装：**在 FBI 中打开 **Remote Install → Scan QR Code**，扫描上方二维码即可安装本次发布的 CIA。二维码固定指向 **0.8.2.1** 安装包。

基于 [ankushKun/3dsDL v0.8.2](https://github.com/ankushKun/3dsDL/releases/tag/v0.8.2) 的多语言分支。版本采用「上游发布版本 + 修订号」：`0.8.2.1`、`0.8.2.2`，之后随上游版本递增。

## What's new

- **设置 → 其他设置 → 语言** 现支持七种语言：English、简体中文、Español、Français、Português、Deutsch、日本語。
- 为新增的西班牙语、法语、葡萄牙语、德语和日语补齐现有语言目录中的全部 **69 项文本**，语言选择在重启后保留。
- 翻译范围与现有中文支持一致，集中在设置界面及下载选项；其余尚未接入语言目录的页面仍显示英文。
- 完成 upstream main 的同步，合并新的日志、压缩包、文件预览等改进，同时保留本分支的本地化功能。
- 支持四段数字版本的打包、应用内版本比较及崩溃符号文件获取。版本顺序为 `0.8.2 < 0.8.2n < 0.8.2.1 < 0.8.2.2 < 0.8.3`。

## Install / Update

- **已有本分支 `0.8.2n`：**可在 **Settings → Updates** 更新为本版；旧版数字比较已能识别第四段修订号。
- **CIA：**扫描上方二维码，或下载下方 `3dsDL.cia` 并使用 FBI 安装。
- **3DSX：**下载 `3dsDL.3dsx`，替换 SD 卡上的旧文件；可将 `3dsDL.smdh` 放在同一目录。
- **从上游原版迁移：**先手动安装本版。此后应用内更新从 **1sm23/3dsDL** 获取发布及校验文件。
- `3dsDL.sha256` 用于核对 CIA / 3DSX；`3dsDL.elf` 用于崩溃分析。

## Validation

- 主机单元测试、集成测试及版本排序检查通过。
- 使用固定工具链构建 CIA / 3DSX，并验证 SHA-256。
- 本次未进行真机字体和安装验证；各语言的字形显示取决于主机现有系统字体。
